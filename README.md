Прототип локальной RAG-системы (Retrieval-Augmented Generation) для умного поиска ответов по закрытым корпоративным документам.

## Набор инструментов
* **Language:** Python 3.11
* **LLM Orchestration:** LangChain (`langchain-ollama`)
* **Local LLM Server:** Ollama (модель `qwen2.5:1.5b` для качественной работы с русским языком, советую его но можно заменит Если не принципиально работать только с русским языком)
* **DevOps / Containerization:** Docker

## Архитектура системы
1. **Context Loading:** Скрипт считывает локальные текстовые регламенты компании (`company_rules.txt`).
2. **Prompt Engineering:** Кастомизированный системный промпт жестко ограничивает ИИ рамками переданного контекста для полной борьбы с "так сказать с Некорректной работы".
3. **Local Inference:** Запрос обрабатывается локально через Ollama API на внутренней инфраструктуре.

## Как запустить проект локально

1. Установите и запустите **Ollama**, скачайте модель:
```bash
ollama pull qwen2.5:1.5b
```

2. Клонируйте репозиторий, настройте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # Для Windows: .\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. Запустите ИИ-ассистента:
```bash
python app.py
```

## Развертывание через Docker
```bash
docker build -t local-rag-app .
```
## Возможные проблемы при запуске

**Проблема:** Ошибка `UnauthorizedAccess` при активации `venv` на Windows.
**Причина:** Параметры безопасности Windows по умолчанию запрещают запуск сторонних скриптов в PowerShell.

**Решение:** Разрешить выполнение сценариев для текущего сеанса. Скопируйте эту команду в терминал:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```
Это безопасно и действует только до тех пор, пока вы не закроете текущее окно консоли.
### Способ 2: Отключить ограничение навсегда
Если вы не хотите вводить команду каждый раз, разрешите запуск скриптов для текущего пользователя:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```
Не советую этот вариант так сильно просядет безопасность на вашем устройстве!, так как любой вирус под видом скрипта сможет запуститься и без труда удалить ваши файлы.
